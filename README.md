# relay-check

在本机自测 AI API 中转站的命令行工具：你填入中转站地址和**你自己的 Key**，
工具向该站发送少量探针请求，检查两件事——

1. **身份**：返回的 `model` 字段、模型的自述身份，和该站声称卖给你的模型是否对得上；
2. **计费**：固定文本探针返回的 `usage`（token 用量），和官方基线用量相比有没有明显虚高。

> 状态：MVP 草稿。完整探针题库不公开，本仓库只含框架与少量示例题。

## 它能做什么，不能做什么

能做的：

- 用少量探针快速筛查「明显不对劲」的信号：返回的模型名对不上、自述身份是另一家、
  固定文本的用量比基线高出一大截。
- 生成带时间、方法与逐题记录的 JSON + Markdown 报告，方便你多次测试后横向对比。

不能做的（重要）：

- **不能给出确定性结论。** 本工具的结论用语只有三种：**疑似**、**未发现异常**、**未测试**。
  「疑似」不等于实锤，「未发现异常」也不等于保证没问题。
- **抓不到 usage 字段本身造假。** 如果服务商直接在返回的用量数字上编造，计费比对会被绕过。
- **长上下文只测小规格。** 为控制单次成本，探针上下文有限，测不出大上下文下的替换、截断。
- **身份信号是弱证据。** 服务商可以用系统提示词让后端模型自称任何身份；
  自述对得上不证明后端真实，自述对不上也可能只是提示词设置。

## 隐私与 Key 安全

- Key **只从环境变量读取**，不接受命令行明文参数，不打印、不写日志、不落盘、
  不进入报告文件。报告里只记录目标地址、模型名与接口格式。
- 工具在本机运行，请求只发往你指定的那个中转站，不经过任何第三方服务器。
- `--dry-run` 可先校验配置并打印脱敏计划（只显示 Key 是否已设置，绝不显示 Key 本身）。

## 使用方法

要求：Python 3.10+，只用标准库，无需安装任何依赖。

```bash
# 1) 把你的 Key 放进环境变量（不要写进任何文件）
export RELAY_CHECK_API_KEY="你的Key"

# 2) 先空跑校验（不发任何请求）
python3 relay_check.py \
  --base-url https://relay.example.com \
  --model claude-sonnet-4-5 \
  --format openai \
  --questions questions.example.json \
  --dry-run

# 3) 正式运行（OpenAI 兼容格式）
python3 relay_check.py \
  --base-url https://relay.example.com \
  --model claude-sonnet-4-5 \
  --format openai \
  --questions questions.example.json \
  --baseline baseline.json \
  --out out/

# Anthropic 格式的站把 --format 换成 anthropic 即可
```

参数要点：

| 参数 | 说明 |
| --- | --- |
| `--base-url` | 中转站地址（不要带末尾路径，工具会拼接 `/v1/...`） |
| `--model` | 该站声称提供的模型名 |
| `--format` | `openai` 或 `anthropic` |
| `--key-env` | 存放 Key 的环境变量名，默认 `RELAY_CHECK_API_KEY` |
| `--questions` | 题目 JSON 文件 |
| `--baseline` | 基线 JSON（可选；不提供时计费类结论为「未测试」） |
| `--threshold` | 计费偏差阈值，默认 `0.2`（总量偏差超过 20% 标记疑似） |
| `--out` | 报告输出目录，生成 `report.json` 与 `report.md` |
| `--dry-run` | 只校验并打印脱敏计划，不发请求 |

## 关于基线

计费核对需要一份基线：同一道题在**官方通道**上多次运行后，返回 usage
的中位数。本仓库的基线覆盖情况：

| 目标模型 | 状态 | 说明 |
| --- | --- | --- |
| DeepSeek | ✅ 已含真实基线 | `baselines/deepseek-official.json`：2026-11-17 经 DeepSeek 官方 API 生成，全量题目每题运行 3 次、usage 取中位数。官方对 deepseek-chat 请求实际返回的 model 字段为 `deepseek-flash`，基线按实测记录。测 DeepSeek 类目标时用它作 `--baseline`。 |
| Claude（Sonnet 级） | ⏳ 待补 | 暂无基线数据，见下。 |
| GPT（专有 GPT 级） | ⏳ 待补 | 暂无基线数据，见下。 |

Claude / GPT 基线待补的原因：生成基线需要付费的官方通道，而项目当前
没有已获预算批准的付费通道（可用的聚合账户从未充值，其最低充值额
超过本项目的预算上限，项目所有者已裁定不充值）。待有合规通道后，
将按与 DeepSeek 基线相同的方法补齐。在此之前，对声称提供 Claude /
GPT 的站点运行时**不要**拿 DeepSeek 基线充数——可以不带 `--baseline`
运行，此时工具会如实把计费类结论写成「未测试」，而不是假装检查过；
身份类检查不依赖基线，仍可正常使用。

## 成本说明

工具本身免费。成本来自探针请求在**被测站**产生的 API 用量，由你自己承担。
按示例题量，精简版一次运行的目标成本是 **不超过约 ¥1**（视该站定价而定）；
请先用 `--dry-run` 确认题目数量，再决定是否运行。

## 自测（开发者）

仓库附带 `fake_relay.py`：一个故意掺假的本地假中转（改写 model 字段 +
放大 usage），用于验证工具能否识别掺假、且不误判正常上游。
它只转发到你用环境变量指定的上游，同样不记录任何 Key。
